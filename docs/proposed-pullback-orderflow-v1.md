# 상승 추세의 눌림 후 매수세 회복 전략 — 설계 제안 v1

작성: 2026-11-05. 상태: 설계만 작성. 구현·학습·백테스트·실시간 모의 실행을 하지 않았다. 아래 숫자는 최적화 결과가 아닌, 향후 비교할 수 있도록 고정한 최초 가설이다.

## 목적과 선택 이유

목표는 비용 차감 후 양의 기대손익을 가진 거래를 고르고, 손실 규모와 누적 낙폭을 통제하면서 계좌 수익 가능성을 높이는 것이다. 거래별 승률만 최적화하지 않는다. 승률이 높아도 드문 큰 손실로 계좌가 손해일 수 있다. 계좌 전체 수익 확률은 개별 승률뿐 아니라 거래 간 상관관계, 손익 크기, 빈도에도 좌우된다.

기존 F3는 최근 5분 고점을 돌파한 직후 짧은 주문흐름 확인으로 매수했다. 제안 v1은 상승 환경을 먼저 확인한 뒤 눌림에서 후보를 만들고, 매수 체결 회복으로 진입을 정한다. 기대 가설은 진입가와 손절 기준을 가까이 두면서 추세 재개 구간을 확보하는 것이다. 눌림이 추세 반전으로 이어지거나 반등 확인이 늦어질 수 있으므로, 이 가설이 기존 전략보다 좋다고 아직 판정하지 않는다.

빠른 관측과 짧은 보유를 분리한다. 호가·체결은 이벤트마다 수집하고 의사결정은 1초 단위로 하되, 포지션은 최대 20분 보유한다. 몇 초의 미세 움직임만으로 왕복 비용을 회수해야 하는 구조를 완화하려는 가설이다. 보유시간을 늘리는 것 자체가 수익 우위를 만들지는 않는다.

## 범위와 데이터

- 첫 대상은 업비트 KRW-BTC 현물 매수 후 매도. 공매도·레버리지는 사용하지 않는 설계다. ETH 등 추가 대상은 이후 별도 선정·보정한다.
- 완성된 1분봉으로 EMA20, EMA60, ATR14, 최근 고점을 계산한다. 미완성 봉을 확정 데이터처럼 사용하지 않는다.
- 호가 및 체결에는 거래소 시각과 수신 시각을 모두 보관한다. 중복, 역순, 교차 호가, 지연 데이터는 진입 판단에서 제외한다.
- 최근 호가가 1초 이상 오래되었거나 관측이 끊겼으면 새 진입을 막는다. 복구 후 특징에 필요한 과거 길이만큼 다시 준비한다.
- 공개 호가 스냅샷으로는 개별 주문 취소·추가·대기 순번을 완전히 복원할 수 없다. 잔량 회복은 관측 특징으로 취급하며 실제 주문의 정체나 숨은 유동성으로 단정하지 않는다.

## 후보 생성과 매수

상태는 `관찰 → 상승 환경 → 눌림 후보 → 회복 확인 → 비용·확률 심사 → 보유 → 재진입 대기`로 고정한다.

1. **상승 환경:** 완성된 1분봉 EMA20 > EMA60이고, EMA20이 5봉 전보다 높을 때만 후보를 만든다. 하락·횡보 환경에서는 이 매수 전략이 대기한다.
2. **눌림 후보:** 최근 10개 완성 봉의 고점을 H로 정한다. H 이후 5분 이내에 가격이 H 대비 0.5~1.5 ATR 하락하고, 완성 봉 종가가 EMA60 밑으로 내려가지 않았으면 후보를 활성화한다. H와 기준 ATR은 후보 생성 때 고정한다. 후보가 5분을 넘거나 EMA60 아래 종가가 나오면 폐기한다.
3. **회복 확인:** 현재 중간가격이 현재 이벤트를 제외한 직전 10초 고점을 넘어가고, 최근 5초의 공격적 매수 체결대금이 공격적 매도 체결대금보다 많은 상태가 3회 연속 1초 평가에서 유지되면 매수 심사로 넘어간다. 겹치는 관측은 독립 증거가 아니므로 확률을 곱하지 않는다. 호가 불균형은 별도 모델 특징이며 큰 매수벽 하나로 매수하지 않는다.
4. **진입 직전 재계산:** 후보 저점 P와 고정 ATR을 기준으로 손절 가격 S = P − 0.2 ATR을 정한다. 현재 주문 수량의 호가 깊이와 지연을 반영한 예상 매수가 E에 대해 D = (E − S) / E를 구한다. D가 0.25~1.20% 밖이면 제외한다. 목표가는 E × (1 + 2D)다. 가격 기준 목표 폭이 추정 왕복 비용의 3배보다 작으면 제외한다.
5. **순수익 심사:** 아래 확률·기대손익 조건을 통과한 후보만 주문한다. 체결 가능 가격, 수량, 비용이 바뀌면 다시 계산한다. 첫 회복 신호 때 중간가격보다 0.25 ATR 이상 비싸져야 체결되는 경우 이번 기회를 건너뛴다.

초기에는 가설 하나만 둔다. 하락장 역추세, 급등 추격, 마켓메이킹을 동시에 섞지 않는다. 신호가 없으면 이유를 기록하고 대기한다.

## 무엇을 학습하는가

모델의 질문은 “다음 호가가 올라갈까?”가 아니라 **“지금 이 수량을 매수해서 아래의 동일한 청산 규칙을 적용하면, 비용 차감 후 이익으로 끝날까?”**다.

최초 모델은 정규화한 특징을 사용하는 규제 로지스틱 회귀다. 데이터가 적을 때 복잡한 모형으로 우연을 학습할 위험을 줄이고, 신호가 판단에 미치는 영향을 확인하기 위한 설계 선택이다. 이 모형의 우월성이 확인되었다는 뜻은 아니다.

초기 입력은 다음 10개로 제한한다.

| 특징 | 의도 |
|---|---|
| (EMA20 − EMA60) / ATR | 상승 추세의 강도 |
| (EMA20 현재 − EMA20 5봉 전) / ATR | 추세가 약해지는지 |
| (H − 후보 저점) / ATR | 눌림의 깊이 |
| 후보 활성화 이후 시간 | 반등 기회의 노후화 |
| 5초 공격적 순매수 체결대금 / 총 체결대금 | 실제 매수 주도성 |
| 직전 5초 대비 순매수 비율 변화 | 매수 흐름 회복 |
| 5초 평균 상위 5호가 매수·매도 잔량 불균형 | 표시된 유동성의 방향 |
| 마이크로프라이스와 중간가격의 차이 / 스프레드 | 최우선 호가 압력 |
| 추정 왕복 비용 / 목표 가격 변동 폭 | 비용 부담 |
| 후보 이후 고점에서 회복 신호 가격까지의 거리 / ATR | 이미 회복을 소진했는지 |

학습 사례는 실제 매수 여부와 무관하게 발생한 모든 유효 후보를 기록한다. 각 후보에 동일한 진입 지연, 주문 크기 정책, 체결 비용, 손절·목표·시간 종료 규칙을 적용해 결과를 붙인다. 미래 데이터를 현재 특징에 섞지 않는다. 미체결은 손실 거래와 구분해 기록하고 실제 주문 시도 단위 기대손익에도 포함한다.

산출값은 다음과 같다.

- p: 비용 차감 후 순손익이 양수일 확률. 시간 종료도 최종 순손익 부호로 포함한다.
- G: 순이익 거래의 조건부 평균 이익률.
- L: 순손실 거래의 조건부 평균 손실률 절댓값.
- 기대 순수익률 μ = p × G − (1 − p) × L. 정확히 0인 거래에 확률 질량이 있으면 그 항을 별도로 두며, 양수·음수 확률 합을 억지로 1로 만들지 않는다.

G와 L은 단순히 고정 목표·손절 폭을 대입하지 않는다. 실제 모형상 체결 지연, 갭, 시간 종료 결과를 포함한 조건부 손익에서 추정한다. 사례가 적은 그룹은 전체 평균으로 수축하고, 추정이 불안정하면 보류한다. p, G, L은 모두 새 거래 시점 이전 자료로 추정해야 한다.

**진입 기준 초안:** 순이익 확률이 추정 손익분기 확률 L / (G + L)보다 5%p 이상 높고, 추정 불확실성을 반영한 기대 순수익률의 보수적 추정치가 +0.05%를 넘어야 한다. 5%p와 0.05%는 최초 설계값이며 검증된 최적값이 아니다. 시간 블록 단위 재표집 등으로 구하는 보수적 추정치는 비정상 시장에서 보장된 신뢰한계가 아니다. 표본이 부족하면 확률을 만들어내지 않고 학습 준비 상태로 둔다.

예를 들어 p=60%, 평균 순이익=0.62%, 평균 순손실=0.58%라면 추정 기대 순수익은 0.14%다. 100만원 진입 시 평균 약 1,400원에 해당한다. 이것은 계산 설명용 가정으로 목표 성과나 현재 예측값이 아니다. 이익·손실 수치에 비용이 이미 들어 있으므로 수수료를 다시 빼지 않는다.

## 청산과 주문

- 진입 직후 S와 2D 목표를 확정한다. 손절은 아래로 넓히지 않고 물타기도 하지 않는다.
- 손절·목표 판정은 해당 수량을 팔 수 있는 호가와 예상 체결가격을 이용한다. 중간가격만 목표를 찍었다고 매도 완료로 처리하지 않는다.
- 우선순위는 계좌·시스템 위험 종료, 손절, 목표, 20분 시간 종료다. 실제 가능한 순서와 체결 지연을 라벨에도 동일하게 적용한다. 손절은 정확한 가격 보장을 뜻하지 않는다.
- 첫 설계에서는 중간 분할 익절과 트레일링을 넣지 않는다. 청산 규칙을 바꾸면 학습 라벨을 전부 다시 만들어야 한다. 30초 보유를 학습하고 다른 규칙으로 파는 불일치를 반복하지 않는다.
- 신규 진입은 허용 가격을 제한한 즉시 체결 방식으로 설계한다. 부분 체결은 실제 수량만 보유로 기록하고 잔량은 취소 확인 뒤 정리한다. 미체결 후 무조건 시장가로 추격하지 않는다. 구체 주문 방식은 향후 거래소 지원 기능에 맞춰 구현한다.
- 긴급 청산은 가격 상한보다 포지션 축소를 우선하며, 체결 실패·부분 체결·재시도 상태를 별도로 둔다.
- 데이터 장애 시 신규 주문은 중지하고 미체결 진입 잔량을 취소한다. 보유분은 유효한 대체 시세·주문 경로로 확인하고 위험 종료를 시도한다. 모든 연결이 끊기면 청산을 보장할 수 없으므로 복구 후 계좌 대조가 필요하다.
- 메이커 수수료 할인이나 가격 접촉만으로 지정가 체결을 가정하지 않는다. 비용은 적용 수수료, 매수·매도 호가 차이, 수량별 깊이, 지연에 따른 추가 불리한 가격 변화를 반영한다. 호가 깊이 체결에 이미 들어간 스프레드를 재차 차감하지 않는다.

## 가상자금 1,000만원의 초기 위험 한도

| 항목 | 설계값 |
|---|---:|
| 한 거래의 계획 손실 예산 | 현재 계좌 평가액의 0.1%: 최초 10,000원 |
| 한 번의 진입 금액 상한 | 현재 평가액의 10%: 최초 1,000,000원 |
| 동시 포지션 | BTC 1개 |
| 하루 신규 진입 중단 | KST 시작 평가액 대비 실현·평가 합산 −0.5% |
| 연속 순손실 3회 | 새 진입 60분 대기 |
| 정상 청산 후 재진입 대기 | 최소 5분, 새로운 눌림 후보 필요 |

주문금액 Q는 `min(10% 계좌, 손실 예산 / (D + 보수적 왕복 비용률), 유동성 허용 금액, 가용 현금)`으로 정한다. 비용률은 Q에 따라 달라지므로 Q를 줄여가며 재계산하고 최종 금액에서도 예산을 충족해야 한다. 예상 손실 예산과 일일 중단선은 급변·통신 장애로 초과될 수 있다. 기준선 도달 시 새 진입을 막고 보유분의 위험 종료를 시도한다.

## 학습 업데이트와 향후 승인 기준

장중 매 거래마다 가중치와 문턱을 바꾸지 않는다. 충분한 체결·호가 이력이 확보된 뒤 과거의 시간순 자료로 후보 모델을 만들고, 그 다음 구간에서 확률 보정과 의사결정 기준을 선택하며, 이후 한 번도 사용하지 않은 구간으로 평가하는 설계다. 최대 20분 보유와 지연만큼 겹치는 라벨을 분리 경계에서 제거한다. 정규화도 학습 구간에만 맞춘다.

모델 확률의 정확성과 거래 정책의 수익성을 별도로 확인해야 한다. 평가 대상은 비용 후 기대손익, 확률 보정, 낙폭, 일별 손익의 쏠림, 동일 노출 단순 보유 비교, 수수료·지연 스트레스다. 가장 높은 과거 수익 하나로 승격시키지 않는다. 거래 기록만 학습하면 선택 편향이 생기므로 미진입 후보의 반사실적 결과도 보존한다.

기존 94일 분봉 자료만으로는 이 주문흐름 모델을 학습할 수 없다. 앞서 관찰한 약 20.6시간의 호가·체결도 안정적인 확률을 주장할 근거로 부족하다. 이미 확인한 기존 홀드아웃은 새 전략의 완전히 미사용 평가 구간으로 재활용하지 않는다. 이는 향후 학습·평가 계획이며 이번 작업에서 실행하지 않았다.

## 연구 근거와 적용 한계

- Cont, Kukanov, Stoikov: 미국 주식 50종에서 짧은 구간 가격변화와 주문흐름 불균형·시장 깊이의 관계를 보고했다. 유동성과 흐름을 함께 보는 근거이며 코인에서의 미래 수익이나 이 눌림 규칙을 증명하지 않는다. https://arxiv.org/abs/1011.6402
- Gould, Bonart: Nasdaq 10종목에서 호가 잔량 불균형을 이용한 다음 중간가격 움직임 분류를 로지스틱 회귀로 연구했다. 단순 확률 모델의 참고 자료이며, 다음 한 틱의 방향을 20분 순수익 확률로 동일시하지 않는다. https://arxiv.org/abs/1512.03492
- Albers et al.: 여러 비트코인 거래소의 미시구조 특징으로 500ms 가격 움직임을 분석했으며 거래비용이 taker 수익에 미치는 영향을 강조한다. 주문흐름과 비용을 함께 평가하는 근거다. 거래소 간 선행 신호는 통화 단위와 시각 동기화 문제를 해결한 뒤 별도 확장 후보로 둔다. https://arxiv.org/abs/2108.09750

이 문서의 결합 전략, 기간, 배수, 진입 문턱은 위 논문이 검증한 조합이 아니라 현재 시스템의 실패 원인을 바탕으로 제안한 새로운 설계 가설이다.
