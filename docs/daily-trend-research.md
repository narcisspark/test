# 일 단위 추세 추종 사전 등록 (pre-registration)

작성: 2026-11-18, **데이터를 받기 전**에 고정한다. 초·분 단위 554개 조합이 모두 비용 후 손실이었다([candidate-algorithms.md](candidate-algorithms.md)). 일 단위는 거래 횟수가 적어 비용 비중이 작고, 코인 시계열 모멘텀은 학술 근거가 비교적 많다. 어떤 결과도 수익 보장이 아니다.

## 목적

승률이 아니라 **매수 후 보유보다 나은 위험 대비 성과**, 특히 2018·2022년 같은 −70~−80% 하락을 피하는 것이 목표다. 추세 추종은 보통 승률 35~45%, 작은 손실 여러 번과 큰 이익 몇 번으로 이루어진다.

## 데이터

- 업비트 공개 일봉 `/v1/candles/days` (UTC 00:00 = KST 09:00 마감). 다운로더: [download_daily.py](../tools/download_daily.py).
- **유니버스(고정):** KRW-BTC, KRW-ETH, KRW-XRP, KRW-ADA, KRW-DOGE, KRW-SOL, KRW-LINK, KRW-ETC. 상장 후 250일이 지나야 포트폴리오에 편입한다.
- **생존 편향 경고:** 지금까지 살아남은 대형 코인을 고른 것이라 과거 성과가 부풀려진다. 매수 후 보유 기준선도 같은 종목으로 계산해 비교 편향을 맞춘다.

## 규칙

- 매일 종가로 신호를 계산하고 **다음 날 수익률부터** 적용한다(당일 정보로 당일 수익을 얻지 않음). 롱 전용, 신호가 꺼지면 현금.
- 비용: 포지션이 바뀔 때마다 편도 0.15%(수수료 0.05% + 슬리피지 0.10%). 스트레스는 0.30%.
- 포트폴리오: 편입 가능한 코인들에 매일 동일 비중. 각 코인 슬롯은 코인 또는 현금이다. 슬롯 간 재조정 비용은 무시하며(낙관적), 기준선도 같은 방식으로 계산한다.

| 계열 | 진입·유지 조건 | 파라미터 |
|---|---|---|
| S1 이동평균 필터 | 종가 > SMA(N) | N ∈ {20, 50, 100, 200} |
| S2 돈치안 돌파 | 종가 > 직전 N일 최고가에 진입, 종가 < 직전 M일 최저가에 청산 | (N, M) ∈ {(20,10), (55,20), (100,50)} |
| S3 시계열 모멘텀 | 직전 L일 수익률 > 0 | L ∈ {30, 90, 180, 365} |
| S4 이중 이동평균 | SMA(f) > SMA(s) | (f, s) ∈ {(10,50), (20,100), (50,200)} |

총 **14개** 변형.

## 검증 규약

- 기간 분할(시간순): 학습 ~2022-12-31, 검증 2023-01-01~2024-06-30, 홀드아웃 2024-07-01~. 홀드아웃은 최종 후보 1개만 `--open-holdout`으로 1회 연다.
- **선택:** 학습 구간 샤프비율 최고 변형. 단, 학습 구간 비용 2배에서도 연복리 수익률 > 0.
- **검증 통과:** 검증 구간 샤프 > 0, 비용 2배 수익 > 0, 최대낙폭(MDD)이 같은 구간 매수 후 보유 MDD보다 작음.
- **홀드아웃 통과:** 같은 조건. 통과해도 1~3개월 실시간 모의 운영 후에만 신뢰한다.
- 지표: 연복리 수익률, 연 변동성, 샤프(무위험 0), MDD, 노출 비율, 거래 수, 거래 승률. 모든 결과에 매수 후 보유를 나란히 기록한다.
- 구현: [daily_trend.py](../tools/daily_trend.py).
